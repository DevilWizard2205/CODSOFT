# Number Guessing Game 🎮

A console-based number guessing game built using C++.

## Features

- Random number generation
- 5 lives per game
- Higher/lower hints
- Marvel/DC themed bonus question
- Conditional hints based on remaining lives

## Concepts Used

- C++
- Functions
- Loops
- Conditional statements
- `map`
- `vector`
- String manipulation
- Random number generation

## How to Run

```bash
g++ "Number Guessing Game.cpp" -o game
./game
